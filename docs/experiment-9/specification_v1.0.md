# PlanMyWay-AI — Version 1.0

1. The user can enter a travel destination.
2. The user can specify trip duration and budget.
3. The user can enter travel preferences.
4. The system generates a personalized itinerary using an AI service.
5. The user can view the generated itinerary, including suggested activities.
6. The system displays travel locations on an interactive map.
7. The user can save trips and view saved itineraries.
8. The user can download the itinerary as a PDF.
